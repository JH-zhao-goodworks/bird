# 小鳥ホテル予約システム

C# WinForms（.NET 10）で作成した、ローカルPCで動く小鳥ホテル向けの籠予約管理アプリです。
ログイン不要、インストール不要（自己完結型の単一exe）で、データはPC内のSQLiteファイルに保存されます。

## 使い方（インストール不要）

実行ファイル名はOSやツールでの文字化けを避けるため英数字（`BirdHotelReservation.exe`）にしています。
ウィンドウ内の表示（タイトルバーや画面）はすべて日本語です。

配布形式は2種類用意しています。

1. **`BirdHotel.App/publish-framework-dependent/`（推奨・まずこちらを試してください）**
   このPCに既に入っている .NET 10 デスクトップランタイムを使って動く軽量版です。
   - `BirdHotelReservation.exe` を直接ダブルクリック、または
   - 同じフォルダの **`起動.bat`** をダブルクリック（`dotnet.exe`経由で起動するため、未署名exeの直接実行がブロックされる環境ではこちらの方が動く可能性があります）
   フォルダ内のdllファイルは削除しないでください。
2. **`BirdHotel.App/publish/BirdHotelReservation.exe`（自己完結型・単一ファイル）**
   .NETランタイムが入っていない別のPCでも動かせるよう、実行に必要な一式を1つのexe（約50MB）にまとめたものです。自己解凍する大きな未署名exeのため、セキュリティソフト（Windows Defenderや会社のEDR）に検疫・ブロックされやすい傾向があります。

開けない場合は「Windows セキュリティ」→「保護の履歴」でブロック記録がないか確認してください。それでも実行できない場合は、会社のセキュリティポリシー（AppLocker/WDAC等）で未署名アプリの実行自体が制限されている可能性があるため、情報システム部門への確認が必要です。

データベースファイルは `%LOCALAPPDATA%\BirdHotelReservation\bird_hotel.db` に自動作成されます。
PCを移す場合はこのファイルをコピーすれば予約データも引き継げます。

## 画面構成

- **ホーム（籠一覧）**: 起動直後に表示。籠ごとにカード表示（籠名の自然順ソート＝1,2,3...の順）。カード内には登録済みの予約が一覧（名前・開始日・終了日・合計日数、期間なしは「無期限」）で並び、同じ飼い主の鳥は同じ背景色になります。定員を超える羽数が同時に入っている籠は見出しに「（特N）」と表示されます。カード（見出しでも表でもどこでも）をクリックすると、その籠に鳥を登録するダイアログが開きます。
- **飼い主の管理**: 飼い主名・連絡先を登録。「経営者本人」にチェックすると、その飼い主の鳥は予約登録時に自動で「期間なし」（退室日未定の長期滞在）になります。「重複を統合」から、同一人物が別名で複数登録されてしまった場合にまとめて1件に統合できます（登録されている鳥は自動的に統合先へ付け替わります）。
- **鳥の管理**: 種類（プルダウン選択、「新規種類...」でその場に追加可能。別途「種類の管理」画面あり、こちらにも表記ゆれ等をまとめる「重複を統合」があります）・名前・生年月日（不明可）・型（中小型/中大型）・性別（オス/メス/不明）・飼い主（プルダウン選択、「新規飼い主...」でその場に追加可能）を登録。「一括登録」から、Excel等で「種類, 名前, 飼い主」をコピーしてまとめて鳥を登録することもできます（未登録の種類・飼い主は自動作成）。「重複を統合」から、同じ鳥が別々に登録されてしまった場合にまとめて1件に統合できます（予約は自動的に統合先へ付け替わります）。
- **籠の管理**: 籠名と定員（既定2羽）を登録。特別に3羽以上を1つの籠にまとめて入れたい場合は定員を直接変更できます。
- **予約登録・空き確認**: 鳥を（飼い主で絞り込んだ上で）複数選択できます。同じ飼い主の複数羽（例: つがいのオカメインコ2羽）を同じ籠・同じ期間でまとめて登録できます。滞在期間（開始日・終了日、または「期間なし」）を入力して「空き籠を確認」を押すと、各籠の予定在籠数・空きが一覧表示されます。空いている籠を選んで登録します。既に鳥がいる籠へさらに登録したい、または定員を超える場合は「定員を超えても登録する」にチェックが必要です。画面右側の予約一覧から、既存の予約の編集（籠・期間・備考の変更）や取消がいつでもできます（ダブルクリックでも編集画面が開きます）。なお、同じ籠でも期間が重ならない予約は共存でき、両方とも一覧に表示されます。
- **予約の一括登録（自動籠配属）**: 「種類, 名前, 飼い主, グループ, 開始日, 終了日」の順でまとめて貼り付けると、鳥の新規登録と予約登録を同時に行い、空いている籠へ自動的に割り当てます。同じ籠に入れたい鳥（例: つがいのオカメインコ）には同じグループ名を付けてください（グループ名・開始日・終了日が一致する行だけ同じ籠にまとまります）。グループ欄が空欄の行は1羽ずつ単独の籠に自動配属されます。

## 開発者向け情報

- ソリューション: `BirdHotel.slnx`（プロジェクト: `BirdHotel.App`）
- ビルド: `dotnet build`
- 自己完結型の単一exeを再生成する場合:

```
dotnet publish BirdHotel.App -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o BirdHotel.App/publish
```

- フレームワーク依存版（軽量・要.NET 10ランタイム）を再生成する場合:

```
dotnet publish BirdHotel.App -c Release -r win-x64 --self-contained false -p:PublishSingleFile=false -o BirdHotel.App/publish-framework-dependent
```

## 既知の制限・今後の拡張候補

- 現状、実行環境の制約によりビルド確認までは行いましたが、実際にPC上でウィンドウを開いての動作確認はできていません。初回起動時は一通り操作を試してください。
- 籠の「特別に2羽以上」は、籠ごとの定員変更、または予約登録時の「定員を超えても登録する」チェックのどちらでも対応できます。
- 予約の重複期間チェックは日付単位（時刻は考慮しない）です。
- 旧バージョン（飼い主をOwners テーブルではなく鳥に直接持たせていた頃）のデータベースを開くと、既存の鳥・籠・予約データはそのまま保持されますが、飼い主名が入力されていなかった鳥は「飼い主未設定」になります。鳥の編集画面から飼い主を割り当ててください。
